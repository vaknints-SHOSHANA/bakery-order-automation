# bakery-order-automation.# אוטומציה להזמנות מאפייה

אוטומציה ב-Make שמחברת 3 רכיבים:

1. Gmail - קולט מיילים חדשים שבנושא שלהם מופיעה המילה "הזמנה"
2. Claude (Anthropic) - קורא את המייל, מחליט אם זו הזמנה, ושולף מוצר וכמות
3. פילטר - מעביר הלאה רק הזמנות אמיתיות
4. Airtable - יוצר שורה חדשה בטבלת המכירות של המאפייה

הנתונים נכנסים לאותו בסיס נתונים שמזין את הדאשבורד מהמטלה הקודמת.

## קבצים
- Integration Gmail, Anthropic Claude.blueprint.json - המבנה המלא של האוטומציה, אפשר לייבא אותו ל-Make
