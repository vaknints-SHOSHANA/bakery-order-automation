 אוטומציה להזמנות מאפייה

אוטומציה ב-Make שקולטת הזמנות מהמייל ומכניסה אותן לטבלת המכירות של המאפייה.

## איך זה עובד
1. **Gmail** – קולט מיילים חדשים שבנושא שלהם מופיעה המילה "הזמנה".
2. **Claude (Anthropic)** – קורא את המייל, מחליט אם זו הזמנה, ושולף מוצר, כמות ושם לקוח. התשובה חוזרת כ-JSON לפי סכמה קבועה.
3. **פילטר "רק הזמנות"** – מעביר הלאה רק מיילים שהם הזמנות אמיתיות.
4. **Airtable** – יוצר שורה חדשה בטבלת המכירות.

הנתונים נכנסים לאותו בסיס נתונים שמזין את הדאשבורד מהמטלה הקודמת.

## עדכונים
- פורמט הפלט של Claude שונה מטקסט ל-JSON schema, כדי שהנתונים יגיעו בצורה מסודרת לפילטר ול-Airtable.
- ה-temperature שונה ל-0, כדי לקבל תשובות עקביות.
- נבדק: מייל הזמנה נכנס לטבלה, ומייל שאינו הזמנה נחסם בפילטר.

## קבצים
- `Integration Gmail, Anthropic Claude.blueprint.json` – המבנה המלא של האוטומציה. אפשר לייבא אותו ל-Make.
